# Graphite Professional — пакет для Codex

Состав:
- DESIGN_AND_IMPLEMENTATION_SPEC.md — требования к дизайну и реализации.
- screens/dark/ — 23 SVG в графитовой теме.
- screens/light/ — 23 SVG в светлой теме.
- overviews/ — SVG-контакт-листы для просмотра всех экранов.
- manifest.json — список экранов.

Передайте Codex исходное техническое задание, этот пакет и репозиторий проекта.

SVG-файлы являются визуальными референсами, а не заменой работающих UI-компонентов.
Все показанные финансовые данные и компании демонстрационные.
