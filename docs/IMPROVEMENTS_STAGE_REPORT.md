## Проверки

- TypeScript: успешно (`node node_modules/typescript/bin/tsc --noEmit`).
- 26 модульных тестов прошли, включая все статусы следующего действия, денежную точность и ошибки переходов.
- Общий браузерный прогон: 17/18 прошли; единственная нестабильность навигации возникла при обновлении исходников во время запуска. Повтор на стабильных файлах: все 7 тестов навигации и новых улучшений прошли.
- Основной путь мастер → запрос банка → ответ → предложение → принятие → завершение прошёл.
- Все сценарии помощника, тем и адаптивности 390/768/1280/1440 прошли.
- В среде периодически возникают сбои запуска Windows-процессов (Access denied / 0xC0000005), поэтому отдельные команды повторялись. Это не ошибки TypeScript или тестируемого приложения.
