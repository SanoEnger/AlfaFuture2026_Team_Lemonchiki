# ФинМаршрут — backend

FastAPI, SQLAlchemy, Alembic и PostgreSQL. Сервер обслуживает клиентский кабинет, рассмотрение заявок и управление доступом сотрудников.

## Запуск

Выполняйте из корня проекта:

~~~powershell
python scripts/setup_env.py
docker compose up --build -d --wait
~~~

API: http://localhost:8000/docs. Проверка состояния: http://localhost:8000/health.

PostgreSQL работает во внутренней сети Docker. Секреты хранятся в корневом .env, который исключён из Git.

## Первый администратор

~~~powershell
docker compose exec api python -m app.manage create-admin
~~~

Команда запросит email и пароль. Новые пароли: 10–24 символа, буквы и цифры. Администратор приглашает сотрудников, клиенты регистрируются самостоятельно. Письма локального окружения доступны на http://localhost:8025.

Аккаунты, компании и заявки при обычном запуске не создаются. Начальная загрузка добавляет только кредитные продукты и материалы для бизнеса.

## Устройство

- app/api — HTTP-контракт, аккаунты, компания и кредитные операции.
- app/services — разрешённые переходы, проверки и расчёт риска.
- app/models.py — модели хранения.
- alembic — последовательные миграции схемы.
- tests — серверные проверки и изолированные тестовые схемы PostgreSQL.
- openapi.json — схема, из которой frontend генерирует типы.

Сеансы хранятся на сервере; браузер получает HttpOnly cookie. Команды защищены CSRF. Права, принадлежность заявки, назначения и ревизии проверяются сервером.

Внешние реестр, БКИ и денежная выдача не подключены. Неподтверждённые сведения отмечаются явно, решение принимает сотрудник.

## Проверки

Из корня проекта:

~~~powershell
docker compose --profile test run --build --rm tests
~~~

Тесты работают с отдельными временными схемами и не создают аккаунты в рабочей схеме.
