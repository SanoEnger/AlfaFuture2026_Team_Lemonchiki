# SMART CREDIT — автономный frontend

React + TypeScript + Vite, Mantine, React Router, TanStack Query, lucide-react. Только интерфейс: без backend, БД, сетевых API и платных сервисов. Шрифт IBM Plex Sans с кириллицей включён в сборку.

Дизайн: Graphite Glow (по умолчанию), Pearl Light и системная тема. Единые токены и адаптированные стили — `src/styles/finance-themes.css`; общая сетка компонентов — `shared/theme/styles.css`. Градиенты применяются к активной заявке, офферу и компактному обзору скоринга. Формы и таблицы остаются матовыми. На широком экране AI-помощник сдвигает рабочую область, на мобильном открывается полноэкранно. Сводка мастера на мобильном сворачивается.

## Запуск

Из каталога `frontend`:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:5173. `/login` содержит вход по email и паролю для локально зарегистрированных тестовых аккаунтов. `/register` запускает демонстрационную регистрацию; одноразовые ссылки подтверждения и восстановления доступны в `/demo-mailbox`. Реальная отправка писем и серверные сессии не подключены. Используйте только вымышленные сведения и отдельные тестовые пароли.

Готовые сценарии доступны отдельно по http://localhost:5173/demo-login: два предпринимателя, два сотрудника и администратор. Переключение этих готовых аккаунтов не является настоящей авторизацией.

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

## Сценарии

Боковое меню по умолчанию занимает 68 px. На компьютере оно раскрывается поверх страницы при наведении или фокусе клавиатуры; Escape закрывает временное раскрытие. Кнопка закрепления оставляет панель шириной 224 px и перестраивает контент. Закрепление сохраняется в браузере. На телефоне меню открывается кнопкой в верхней панели и закрывается выбором раздела, Escape или нажатием вне панели. На больших сенсорных экранах меню открывается нажатием на иконку меню в панели, с затемнением фона. В кабинете банка «Рассмотрение» и «История решений» — фильтрованные представления существующего маршрута `/bank/applications` с параметром `view`.

- ООО «Вектор»: заявка 1042 на рассмотрении, 1038 с предложением, 1035 с запросом сведений, завершённая заявка и черновик.
- Новый клиент: регистрация → подтверждение в демонстрационной почте → вход → настройка компании → пустой кабинет → первая заявка. Компания редактируется отдельно от сведений отправленных заявок.
- Администратор: приглашение сотрудника → активация из демонстрационной почты → блокировка/восстановление и аудит. Сотрудник берёт свободную заявку в работу; кредитное решение доступно назначенному сотруднику, администратор может переназначить ответственность.
- ИП Сервис: примеры высокого риска и отказа; другая новостная лента.
- Создайте заявку в мастере, сохраните черновик и отправьте. Выйдите и выберите банк, откройте ту же заявку, предложите условия или запросите сведения. Вернитесь под клиентом и ответьте на запрос либо примите/отклоните предложение.
- Принятие предложения переводит заявку в `ACCEPTED`. Отдельная кнопка «Завершить демосценарий» с подтверждением переводит в `COMPLETED`; деньги не выдаются.
- PDF до 5 МБ проверяется локально по расширению и сигнатуре. Сохраняются только метаданные; содержимое файла не сохраняется.
- Тёмная, светлая и системная темы, плотность и уменьшение движения доступны в настройках.
- «Помощник» работает как локальный Demo FAQ без LLM. Учитывает выбранный продукт, заявку, документы и предложение; показывает источники и ссылки на соответствующие разделы. История разделена по пользователю и контексту и хранится в памяти до перезагрузки. Помощник не меняет заявки и не принимает кредитные решения.

Панель помощника имеет ширину 420 px, на экранах от 1440 px расширяется до 580 px; на телефоне занимает весь экран. Шапка, контекст, три быстрых вопроса и поле ввода закреплены, прокручивается переписка. Enter отправляет сообщение, Shift+Enter добавляет строку, Escape закрывает панель. Стили находятся в `src/styles/ai-assistant.css`, модуль — в `src/features/assistant`.

Данные заявок, компаний и демонстрационных аккаунтов хранятся в localStorage текущего браузера. Пароли записываются только как PBKDF2-хеш с солью; это не делает браузерный деморежим серверной аутентификацией. Роль и локальный сеанс — в sessionStorage вкладки; блокировка/смена пароля отзывают локальные сеансы. Демопочта открыта внутри этого браузера. Сброс исходных кредитных примеров доступен в настройках и не очищает аккаунты. Это UI-симуляция без реальных проверок, выдачи средств и серверного контроля доступа. Макеты находятся в `../docs/frontend-reference/`.

## Подключение к API

Серверный режим доступен отдельно: `/server-login`. Используется действующий `/api/v1/auth/demo-login`, роль и сеанс проверяются через `/auth/me`. Демо-учётные записи описаны в `../backend/README.md`. Токен учебного Bearer API хранится в sessionStorage вкладки, очищается при выходе/401; после перезагрузки роль и каталог заново проверяются сервером. Это существующий demo-протокол, а не cookie-аутентификация из полного master-ТЗ.

При `npm.cmd run dev` запросы `/api` проксируются на `http://127.0.0.1:8000`. Для другого адреса задайте `VITE_API_BASE_URL`, например `http://127.0.0.1:8000/api/v1`. В Docker frontend обслуживается Nginx, который проксирует `/api` в сервис `api`.

В режиме API работают продукты с UUID сервера, компании, заявки, сохранение/отправка, история, запросы банка, загрузка/скачивание PDF, предложения, отказ, принятие/отклонение, отдельное завершение и чтение данных помощником. Финансовая форма не копируется в localStorage; сохраняется только ID серверного черновика в sessionStorage. Ошибка сервера не подменяется локальными примерами.

Регистрация/письма/приглашения/администрирование и назначение ответственного пока доступны только в автономном деморежиме. В серверном режиме соответствующие недоступные возможности обозначены или скрыты. Существующий backend не имеет этих контрактов; они не имитируются сетевыми заглушками.

Схемы TypeScript генерируются из `backend/openapi.json`:

```powershell
npm.cmd run generate:api
```

HTTP-интеграционный тест автоматически запускает отдельный FastAPI на 8011 и Vite на 5174. Использует только новую синтетическую SQLite в `../.local/api-ui-*`, не существующую БД:

```powershell
npm.cmd run test:api
```

## Браузерные проверки автономного режима

```powershell
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

Тесты автоматически запускают Vite и проверяют маршруты, локальный workflow, темы и мобильную ширину. Скриншоты записываются в `test-results`.
