# SMART CREDIT — автономный frontend

React + TypeScript + Vite, Mantine, React Router, TanStack Query, lucide-react. Только интерфейс: без backend, БД, сетевых API и платных сервисов. Шрифт IBM Plex Sans с кириллицей включён в сборку.

Дизайн: Graphite Glow (по умолчанию), Pearl Light и системная тема. Единые токены и адаптированные стили — `src/styles/finance-themes.css`; общая сетка компонентов — `shared/theme/styles.css`. Градиенты применяются к активной заявке, офферу и компактному обзору скоринга. Формы и таблицы остаются матовыми. На широком экране AI-помощник сдвигает рабочую область, на мобильном открывается полноэкранно. Сводка мастера на мобильном сворачивается.

## Запуск

Из каталога `frontend`:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:5173. Выберите предпринимателя или сотрудника банка. Пароль не нужен: это переключение демонстрационной роли, а не настоящая авторизация.

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

## Сценарии

Боковое меню по умолчанию занимает 68 px. На компьютере оно раскрывается поверх страницы при наведении или фокусе клавиатуры; Escape закрывает временное раскрытие. Кнопка закрепления оставляет панель шириной 224 px и перестраивает контент. Закрепление сохраняется в браузере. На телефоне меню открывается кнопкой в верхней панели и закрывается выбором раздела, Escape или нажатием вне панели. На больших сенсорных экранах меню открывается нажатием на иконку меню в панели, с затемнением фона. В кабинете банка «Рассмотрение» и «История решений» — фильтрованные представления существующего маршрута `/bank/applications` с параметром `view`.

- ООО «Вектор»: заявка 1042 на рассмотрении, 1038 с предложением, 1035 с запросом сведений, завершённая заявка и черновик.
- ИП Сервис: примеры высокого риска и отказа; другая новостная лента.
- Создайте заявку в мастере, сохраните черновик и отправьте. Выйдите и выберите банк, откройте ту же заявку, предложите условия или запросите сведения. Вернитесь под клиентом и ответьте на запрос либо примите/отклоните предложение.
- PDF до 5 МБ проверяется локально по расширению и сигнатуре. Сохраняются только метаданные; содержимое файла не сохраняется.
- Тёмная, светлая и системная темы, плотность и уменьшение движения доступны в настройках.
- Демо-FAQ работает локально, без LLM. Не принимает кредитные решения.

Данные заявок хранятся в localStorage текущего браузера. Роль — в sessionStorage вкладки. Сброс к исходным примерам доступен в настройках. Это UI-симуляция без реальных проверок, выдачи средств и серверного контроля доступа. Макеты находятся в `../docs/frontend-reference/`.

## E2E

```powershell
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

Тесты автоматически запускают Vite и проверяют маршруты, локальный workflow, темы и мобильную ширину. Скриншоты записываются в `test-results`.
